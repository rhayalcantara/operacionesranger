## Decisiones Técnicas Tomadas

### Decisión 1: Validación en capas

**Justificación**: Separar responsabilidades y proveer feedback claro al usuario

**Capas implementadas**:
1. **Zod Schema** (validaciones básicas de formato y rangos)
   - Valida tipos, rangos de horas, formato de fecha
   - Retorna 400 con mensajes descriptivos
2. **Service Pre-SP** (validaciones de existencia)
   - Valida empleado en BD RRHH (activo)
   - Valida puesto en BD turnos (activo)
   - Retorna 404 o 400 con mensajes específicos
3. **Stored Procedure** (lógica de negocio)
   - Detecta duplicados
   - Calcula tipo_turno y es_feriado
   - Retorna 409 para duplicados
4. **Trigger** (validación final de límites)
   - Valida horas totales <= 16
   - Retorna 400 si se excede

## Notas Adicionales

### Integración con Stored Procedure

**SP**: `sp_registrar_turno`
**Ubicación**: `sistema_turnos_guardianes.sql` (líneas ~1089-1237)

**Parámetros**:
```sql
IN p_empleado_id INT,
IN p_puesto_id INT,
IN p_fecha DATE,
IN p_hora_entrada TIME,
IN p_hora_salida TIME,
IN p_horas_normales DECIMAL(4,2),
IN p_horas_extras DECIMAL(4,2),
IN p_observaciones TEXT,
IN p_created_by INT,
OUT p_turno_id BIGINT,
OUT p_mensaje VARCHAR(255)
```

**Acciones del SP**:
1. Verificar duplicados (empleado+puesto+fecha)
2. Llamar a `sp_determinar_tipo_turno(hora_entrada)` → tipo_turno
3. Llamar a `sp_verificar_feriado(fecha)` → es_feriado, feriado_id
4. INSERT INTO turnos
5. Retornar turno_id y mensaje

---

### Constraint Unique

```sql
CONSTRAINT uk_empleado_puesto_fecha UNIQUE (empleado_id, puesto_id, fecha)
```

Si se intenta duplicar, MySQL retorna error 1062 (Duplicate entry).
El servicio detecta esto y lanza `TurnoDuplicadoError` → 409 Conflict.

---

### Trigger de Validación

```sql
trg_turnos_before_insert:
  IF (NEW.horas_normales + NEW.horas_extras) > 16 THEN
    SIGNAL SQLSTATE '45000'
    SET MESSAGE_TEXT = 'Total de horas excede el máximo permitido (16 horas)'
```

El trigger actúa como última línea de defensa. Zod debería capturar el error primero.

---

### Campos Auto-Calculados (NO en DTO)

**Calculados por SP**:
- `tipo_turno`: DIURNO (entrada 06:00-18:00) o NOCTURNO (18:00-06:00)
- `es_feriado`: true si fecha está en tabla `feriados`
- `feriado_id`: ID del feriado si `es_feriado = true`

**Defaults de BD**:
- `procesado_nomina`: false
- `nomina_id`: NULL
- `fecha_procesado`: NULL
- `created_at`: CURRENT_TIMESTAMP
- `updated_at`: CURRENT_TIMESTAMP ON UPDATE
