## Validaciones Implementadas

### 1. Validación de Código Único por Cliente
```typescript
codigoUnicoValidator(): AsyncValidatorFn {
  return (control: AbstractControl): Observable<ValidationErrors | null> => {
    const clienteId = this.ubicacionForm?.get('cliente_id')?.value;
    if (!clienteId || !control.value) return of(null);

    const excludeId = this.data?.ubicacion?.id;
    return of(control.value).pipe(
      debounceTime(500),
      switchMap(codigo =>
        this.ubicacionesService.validarCodigoUnico(clienteId, codigo, excludeId)
      ),
      map(esUnico => esUnico ? null : { codigoDuplicado: true }),
      catchError(() => of(null))
    );
  };
}
```

### 2. Validación de Coordenadas GPS
```typescript
coordenadasGpsValidator() {
  return (control: AbstractControl): ValidationErrors | null => {
    if (!control.value) return null;
    const pattern = /^-?\d+\.\d+,-?\d+\.\d+$/;
    return pattern.test(control.value) ? null : { formatoInvalido: true };
  };
}
```

### 3. Selector en Cascada Provincia → Municipio
```typescript
setupProvinciaMunicipioListener(): void {
  this.ubicacionForm.get('provincia')?.valueChanges.subscribe(provincia => {
    // Limpiar municipio al cambiar provincia
    this.ubicacionForm.patchValue({ municipio: null });

    // Actualizar lista de municipios
    this.municipiosDisponibles = provincia
      ? MUNICIPIOS_POR_PROVINCIA[provincia] || []
      : [];
  });
}
```

### 1. Integración con ClientesService
El módulo reutiliza `ClientesService` (creado en T3.05) para:
- Cargar clientes activos en el filtro del componente principal
- Cargar clientes activos en el selector del formulario

### 2. Filtro por Cliente
- Selector de clientes en la barra de filtros
- Botón para limpiar el filtro
- Refresca automáticamente la lista al cambiar cliente
- Resetea la página a 0 al filtrar

### 3. Búsqueda con Debounce
- Debounce de 500ms para evitar múltiples requests
- Búsqueda en nombre y código
- Resetea la página a 0 al buscar

### 4. Validación Asíncrona
- Verifica unicidad de código dentro del cliente seleccionado
- Excluye el ID de la ubicación actual en modo edición
- Debounce de 500ms para evitar múltiples validaciones
- Mensaje de error específico: "El código ya existe para este cliente"

### 5. Mensajes de Notificación
- ✅ "Ubicación creada exitosamente"

- ⚠️ "El código ya existe para este cliente"
- ⚠️ "Formato de coordenadas inválido (use: lat,lng)"

### 6. Responsive Design
- Desktop: Todas las columnas visibles
