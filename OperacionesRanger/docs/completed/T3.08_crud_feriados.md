## Problemas Encontrados y Soluciones

### 1. **Problema**: Angular Lexer Error con carácter "ñ" en templates
**Error**: `Unexpected character [ñ] at column 2 in expression [añoSeleccionado]`

**Causa**: Angular tiene problemas con caracteres especiales en nombres de variables en templates HTML

**Solución**: Renombrar todas las variables con "ñ" a "ni":
- `añoSeleccionado` → `anioSeleccionado`
- `añosDisponibles` → `aniosDisponibles`
- `onAñoChange()` → `onAnioChange()`
- `feriadosDelAño` → `feriadosDelAnio`

### 2. **Problema**: MatCalendar no exportado por Angular Material Core
**Error**: `Module '@angular/material/core' has no exported member 'MatCalendar'`

**Causa**: En versiones modernas de Angular Material, MatCalendar no se exporta directamente desde core

**Solución**: Eliminar el `@ViewChild(MatCalendar)` y usar directamente el calendario sin referencia TypeScript. El `dateClass` y eventos funcionan sin necesidad de referencia programática.

### 3. **Problema**: Tipo `Date | null` en evento selectedChange
**Error**: `Argument of type 'Date | null' is not assignable to parameter of type 'Date'`

**Causa**: MatCalendar puede emitir `null` en el evento `selectedChange`

**Solución**: Cambiar firma del método:
```typescript
onDateSelected(date: Date | null): void {
  if (!date) return;
  // ...resto del código
}
```
