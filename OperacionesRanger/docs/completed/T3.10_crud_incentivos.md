## Objetivo

Implementar módulo completo para gestión de incentivos por puesto y quincena con cálculo automático de valor hora, incluyendo:

- Lista paginada con filtros por puesto (autocomplete) y rango de fechas
- Selector jerárquico Cliente → Ubicación → Puesto
- Formulario con validación de solapamiento de fechas
- Cálculo automático y reactivo de valor_hora
- Validación de fechas (quincena_inicio < quincena_fin)
- Integración con endpoint /quincena/:fecha

## Archivos Creados

### 1. Servicio de Incentivos

**Archivo**: `frontend/src/app/core/services/incentivos.service.ts`

**Interfaces**:
```typescript
interface Incentivo {
  id: number;
  puesto_id: number;
  quincena_inicio: string;
  quincena_fin: string;
  monto: number;
  concepto?: string;
  valor_hora: number; // Auto-calculado
  activo: boolean;
  puesto?: {
    id: number;
    codigo: string;
    nombre: string;
    ubicacion: {
      id: number;
      nombre: string;
      cliente: {
        id: number;
        nombre: string;
      };
    };
  };
}

interface IncentivosResponse {
  data: Incentivo[];
  total: number;
}

interface IncentivosFilters {
  page?: number;
  pageSize?: number;
  puesto_id?: number;
  fecha_inicio?: string;
  fecha_fin?: string;
  activo?: boolean;
}
```

**Métodos principales**:
- `getAll(filters?: IncentivosFilters): Observable<IncentivosResponse>` - Lista paginada con filtros
- `getById(id: number): Observable<Incentivo>` - Obtener por ID
- `getIncentivosPorQuincena(fecha: string): Observable<Incentivo[]>` - Incentivos activos para una fecha
- `create(incentivo: Partial<Incentivo>): Observable<Incentivo>` - Crear incentivo
- `update(id: number, incentivo: Partial<Incentivo>): Observable<Incentivo>` - Actualizar incentivo
- `delete(id: number): Observable<void>` - Eliminar incentivo
- `validarNoSolapamiento(puestoId, inicio, fin, excludeId?): Observable<boolean>` - Validar fechas
- `calcularValorHora(monto: number): number` - Calcular valor hora (monto / 360)

**Endpoints utilizados**:
- `GET /api/incentivos` (con query params)
- `GET /api/incentivos/:id`
- `GET /api/incentivos/quincena/:fecha`
- `POST /api/incentivos`
- `PUT /api/incentivos/:id`
- `DELETE /api/incentivos/:id`
- `GET /api/incentivos/validar-solapamiento` (con query params)

## Validaciones Implementadas

### Validaciones Síncronas

1. **Campos requeridos**: cliente, ubicación, puesto, quincena_inicio, quincena_fin, monto
2. **Monto mínimo**: > 0.01 (Validators.min)
3. **Concepto máximo**: 255 caracteres (Validators.maxLength)
4. **Quincena fin > inicio**: Custom validator `fechaFinMayorQueInicioValidator()`

### Validaciones Asíncronas

1. **No solapamiento de fechas**: `noSolapamientoValidator()`
   - Verifica que no exista otro incentivo activo para el mismo puesto en el rango de fechas
   - Endpoint: `GET /api/incentivos/validar-solapamiento`
   - Debounce: 500ms
   - Excluye ID actual en edición

## Notas Técnicas

### Cálculo de Valor Hora

**Fórmula**: `valor_hora = monto / 360`

**Explicación**:
- Quincena estándar: 15 días
- Horas por día: 24 horas
- Total: 15 × 24 = 360 horas

**Implementación**:
- Backend: Columna `GENERATED ALWAYS AS (monto / 360) STORED`
- Frontend: Cálculo auxiliar para preview en tiempo real

### Formato de Fechas

- Input: `Date` object (Angular Material Datepicker)
- Formato para backend: ISO `YYYY-MM-DD`
- Función helper: `formatearFecha(fecha: Date): string`

### Selector Jerárquico

**Estrategia**:
1. Cargar clientes al inicializar componente
2. Listener en `cliente_id_selector` → cargar ubicaciones
3. Listener en `ubicacion_id_selector` → cargar puestos
4. Limpiar dependientes al cambiar nivel superior

**Modo edición**:
- Prellenar cliente → esperar carga de ubicaciones
- Prellenar ubicación → esperar carga de puestos
- Prellenar puesto final
