## Configuración de Connection Pools

### BD Principal (turnos_guardianes)
```typescript
{
  host: process.env.DB_TURNOS_HOST,
  port: Number(process.env.DB_TURNOS_PORT),
  database: process.env.DB_TURNOS_NAME,
  user: process.env.DB_TURNOS_USER,
  password: process.env.DB_TURNOS_PASSWORD,
  connectionLimit: 10,           // Alta carga (lectura/escritura)
  queueLimit: 0,                 // Sin límite de cola
  waitForConnections: true,      // Esperar si no hay conexiones disponibles
  enableKeepAlive: true,         // Mantener conexiones vivas
  keepAliveInitialDelay: 0
}
```

### BD RRHH (db_aae4a2_ranger) - Read-only
```typescript
{
  host: process.env.DB_RRHH_HOST,
  port: Number(process.env.DB_RRHH_PORT),
  database: process.env.DB_RRHH_NAME,
  user: process.env.DB_RRHH_USER,
  password: process.env.DB_RRHH_PASSWORD,
  connectionLimit: 5,            // Carga baja (solo lectura)
  queueLimit: 0,
  waitForConnections: true,
  enableKeepAlive: true,
  keepAliveInitialDelay: 0
}
```

## Riesgos y Consideraciones

### Riesgo 1: Credenciales incorrectas en .env
**Mitigación**:
- Validar variables antes de crear pool
- Mensaje de error claro si faltan variables
- Script de prueba independiente para validar credenciales

### Riesgo 2: BD RRHH no accesible
**Mitigación**:
- Intentar conexión en script de prueba primero
- Manejo graceful si BD RRHH falla (permitir arranque del servidor con advertencia)
- Logs detallados del error

### Riesgo 3: Timeout en conexiones
**Mitigación**:
- Configurar timeout razonable (10 segundos)
- Retry logic en función testConnection()
- Mensaje claro si MySQL no está corriendo

### Riesgo 4: Path aliases no funcionan en scripts/
**Mitigación**:
- Usar rutas relativas en scripts si es necesario
- Documentar si se requiere tsconfig-paths

### Riesgo 5: Conflicto con otros subagentes (T009 y T011)
**Mitigación**:
- T007 modifica: `src/config/database.ts` (NUEVO), `.env`, `backend/README.md` (sección DB)
- T009 modifica: `.env.example`, `src/config/env.ts`, `backend/README.md` (sección env)
- T011 modifica: `docs/decisions/002_*.md` (solo docs)
- **Conflicto potencial**: `backend/README.md` (T007 y T009)
- **Solución**: T007 modificará sección "Configuración de Base de Datos", T009 modificará sección "Variables de entorno". Secciones distintas, bajo riesgo.
