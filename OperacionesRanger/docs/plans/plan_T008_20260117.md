### 4. Script query-examples.ts - Queries de ejemplo comunes

**Descripción**: Script que ejecuta y muestra resultados de queries comunes del sistema

**Archivos a crear**:
- `backend/scripts/query-examples.ts`

**Queries a incluir**:

1. **Listar guardianes activos** (desde BD RRHH):
   ```sql
   SELECT id_empleado, cedula_empleado,
          CONCAT(nombres, ' ', apellidos) AS nombre_completo,
          status
   FROM rh_empleado
   WHERE id_puesto = 97 AND status = 1
   ORDER BY apellidos, nombres
   LIMIT 10;
   ```

2. **Turnos registrados últimos 7 días**:
   ```sql
   SELECT t.id_turno, t.fecha, t.empleado_id, t.puesto_id,
          t.horas_normales, t.horas_extras, t.tipo_turno, t.es_feriado
   FROM turnos t
   WHERE t.fecha >= DATE_SUB(CURDATE(), INTERVAL 7 DAY)
   ORDER BY t.fecha DESC, t.empleado_id
   LIMIT 20;
   ```

3. **Resumen de horas por empleado (últimos 15 días)**:
   ```sql
   SELECT empleado_id,
          COUNT(*) as total_turnos,
          SUM(horas_normales) as total_horas_normales,
          SUM(horas_extras) as total_horas_extras,
          SUM(horas_normales + horas_extras) as total_horas
   FROM turnos
   WHERE fecha >= DATE_SUB(CURDATE(), INTERVAL 15 DAY)
   GROUP BY empleado_id
   ORDER BY total_horas DESC
   LIMIT 10;
   ```

4. **Puestos con incentivos activos**:
   ```sql
   SELECT p.id_puesto, p.codigo, p.nombre, p.descripcion,
          u.nombre as ubicacion,
          i.quincena_inicio, i.quincena_fin, i.monto, i.valor_hora
   FROM puestos p
   INNER JOIN ubicaciones u ON p.ubicacion_id = u.id_ubicacion
   LEFT JOIN incentivos_puesto i ON p.id_puesto = i.puesto_id
   ORDER BY p.codigo
   LIMIT 10;
   ```

5. **Feriados del año actual**:
   ```sql
   SELECT fecha, nombre, tipo, descripcion
   FROM feriados
   WHERE YEAR(fecha) = YEAR(CURDATE())
   ORDER BY fecha;
   ```

6. **Llamar procedimiento sp_verificar_feriado**:
   ```sql
   CALL sp_verificar_feriado('2026-01-01');
   CALL sp_verificar_feriado(CURDATE());
   ```

7. **Llamar procedimiento sp_determinar_tipo_turno**:
   ```sql
   CALL sp_determinar_tipo_turno('08:00:00');
   CALL sp_determinar_tipo_turno('20:00:00');
   ```

**Formato de salida**:
- Mostrar título de cada query
- Mostrar SQL ejecutado
- Mostrar resultados en formato tabla (console.table)
- Mostrar tiempo de ejecución de cada query

**Resultado esperado**: Documentación interactiva de queries comunes del sistema

## Riesgos y Consideraciones

### Riesgo 1: Ejecución accidental en producción
**Mitigación**: Validar `NODE_ENV !== 'production'` en scripts destructivos y solicitar confirmación

### Riesgo 2: Cálculo incorrecto de fechas móviles
**Mitigación**: Usar librerías confiables o algoritmos validados para Viernes Santo y Corpus Christi

### Riesgo 3: Conflicto con T010 en backend/README.md
**Mitigación**: T008 se ejecuta ANTES de T010 (secuencial). T010 incorporará cambios de T008

### Riesgo 4: Scripts no funcionan en Windows
**Mitigación**: Usar rutas cross-platform con path.join() y probar en Windows
