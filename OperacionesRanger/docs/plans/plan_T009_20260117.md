## Notas Adicionales

### Variables de Entorno por Categoría

**1. Base de Datos Principal - Turnos**
- DB_TURNOS_HOST: Host del servidor MySQL (localhost en dev)
- DB_TURNOS_PORT: Puerto de MySQL (3306 por defecto)
- DB_TURNOS_NAME: Nombre de la base de datos (turnos_guardianes)
- DB_TURNOS_USER: Usuario de MySQL con permisos de lectura/escritura
- DB_TURNOS_PASSWORD: Contraseña del usuario

**2. Base de Datos RRHH (Read-Only)**
- DB_RRHH_HOST: Host del servidor MySQL (localhost en dev)
- DB_RRHH_PORT: Puerto de MySQL (3306 por defecto)
- DB_RRHH_NAME: Nombre de la base de datos (db_aae4a2_ranger)
- DB_RRHH_USER: Usuario de MySQL con permisos de solo lectura
- DB_RRHH_PASSWORD: Contraseña del usuario

**3. Servidor**
- NODE_ENV: Ambiente de ejecución (development | production | test)
- PORT: Puerto donde escucha el servidor Express
- LOG_LEVEL: Nivel de logging (error | warn | info | debug)

**4. Seguridad (Fase 2)**
- JWT_SECRET: Secreto para firmar tokens JWT (mínimo 32 caracteres)
- JWT_EXPIRES_IN: Tiempo de expiración de tokens (ej: 1h, 24h, 7d)

**5. CORS**
- CORS_ORIGIN: URL del frontend permitida para CORS

**6. Localización**
- TZ: Zona horaria del sistema (America/Santo_Domingo para RD)

### Estructura del archivo env.ts

```typescript
interface EnvConfig {
  // Database - Turnos
  dbTurnos: {
    host: string;
    port: number;
    name: string;
    user: string;
    password: string;
  };

  // Database - RRHH
  dbRrhh: {
    host: string;
    port: number;
    name: string;
    user: string;
    password: string;
  };

  // Server
  server: {
    nodeEnv: 'development' | 'production' | 'test';
    port: number;
    logLevel: 'error' | 'warn' | 'info' | 'debug';
  };

  // Security
  security: {
    jwtSecret?: string;
    jwtExpiresIn?: string;
  };

  // CORS
  cors: {
    origin: string;
  };

  // Localization
  timezone: string;
}
```

### Mensajes de Error Esperados

Cuando falta una variable crítica:
```
ERROR: Variable de entorno requerida no encontrada: DB_TURNOS_HOST

Para resolver este error:
1. Copia el archivo .env.example a .env
2. Edita .env y configura el valor de DB_TURNOS_HOST
3. Reinicia el servidor

Ejemplo:
DB_TURNOS_HOST=localhost
```
